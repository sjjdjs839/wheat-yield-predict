## 四、规则说明

- **同日重复上传**：同一县区同一日期再次上传会覆盖旧记录，不会重复累加。
- **清空复位**：页面上点「清空本期观测」可删除当前县区、当前年份的全部累积记录。
- **换县区 / 年份**：县区在页面下拉选择；年份在年份框输入。文件内日期的年份需与所选年份一致。
- **日期口径**：文件使用完整日期（YYYY-MM-DD），系统按「月-日」自动归入对应生育期。
