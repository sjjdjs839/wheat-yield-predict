# 演示数据说明（上蔡县 2026 年）

## 推荐演示顺序
1. 打开 `/upload`，上传 `01_上蔡县_2026_返青期_0220-0310.csv`，地区名称填「上蔡县」
   -> 页面显示校验通过 + 诊断结论（识别低温日 2 天，未达显著减产阈值，只报暴露强度）
2. 点「去农事建议」-> 返青期出现「19 天记录」，其余四期显示待上传
3. 依次上传 02—05 四份 -> 累积 111 天，五期齐备后顶部上传条自动收起
4. （可选）点某一期的「清空该阶段」-> 该期归零、上传入口重新出现；再点撤销恢复

## 反例演示（说明系统不是"什么都收"）
- `反例_缺少平均气温列.csv` -> 校验未通过，明确报「缺少必需字段：平均温」
- `反例_日期与日序混用.csv`  -> 校验未通过，报「日期口径混用，请只保留一种口径」

## 说明口径（评委会问）
- 2026 年数据为扩展年，参与灾害诊断与当期建议，不参与 2010—2024 历史建模
- 单年不足 300 天只会给「info 级」提示，不阻断上传（分生育期上传本来就只有十几到三十几天）
- 上传后写入的是「当期观测」，不替换全站数据集；要替换需勾选对应选项
