# 现场演示启动卡片

> 本机实测，2026-11-19。**所有路径都相对解压目录，不写死开发机盘符。**

## 一、开场前 3 分钟（必须做）

1. 打开解压后的**交付包文件夹**，双击根目录的 **`启动小麦系统.bat`**
2. 等一个黑色控制台窗口出现，里面会依次打印：Python 路径 → 依赖检查 → 服务地址
3. **再等约 30 秒**，浏览器会自动弹出 `http://127.0.0.1:5000`
   - 开发机实测：双击后 22 秒端口还没监听，约 30 秒才可访问
   - 换一台机器第一次启动会更慢（依赖导入 + 模型文件加载），等 40 秒也不奇怪
   - **浏览器自己弹出来 = 真的起来了**，不用手动刷新
4. 停在首页，别再动

## 二、三条硬规矩

| 规矩 | 原因 |
|---|---|
| **不要关那个黑色控制台窗口** | 服务是前台进程，关窗即停。演示到一半关掉，全站 500 |
| **不要按 Ctrl+C** | 同上，会杀掉服务 |
| **演示前别重启电脑** | MySQL80 虽是开机自启，但服务还要重新拉起，多等 30 秒容易慌 |

## 三、如果双击 bat 没反应

按顺序试，一般到第 2 步就能解决：

1. **在解压后的 `wheat-ml` 文件夹里手动起服务**：打开这个文件夹，在地址栏输入 `cmd` 回车，然后执行
   ```
   python run.py
   ```
   （若系统提示找不到 `python`，改用 `py run.py`，或换成你机器上 Python 的完整路径）
2. 看到 `Running on http://127.0.0.1:5000` 就是起来了，再打开浏览器

如果控制台报「端口被占用」：

```powershell
# 查占用
Get-NetTCPConnection -LocalPort 5000 -State Listen
# 杀掉旧进程（把 PID 换成上一条查到的）
Stop-Process -Id <PID> -Force
```

再双击 bat。

## 四、本机已确认的三个前提（不用再担心）

| 前提 | 状态 | 依据 |
|---|---|---|
| MySQL80 服务 | **Running + 开机自启（Automatic）** | 开发机服务管理器实测 |
| MySQL 挂掉时的兜底 | **可用**：自动落本地 CSV，写入 19 行、读回 19 行、阶段统计正常 | 模拟 `available()=False` 实测 |
| 双击 bat 能起服务 | **能**，约 30 秒就绪 | 开发机实跑，HTTP 200；换机后首次可能更慢 |
