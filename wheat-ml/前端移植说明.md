## 5. 维护提示

1. **图表库**：分析页 / 预测页使用本地 `vendor/chart.umd.min.js`；地图页使用本地 `vendor/echarts.min.js`。升级时保持 UMD 版本，替换同名文件即可。
2. **新增分析图表**：在 `src/analysis/web_charts.py` 增加规格，在 `web/static/app.js` 的 `renderers` 注册同名渲染函数，模板用 `<script type="application/json" class="chart-spec">` 传入。
3. **替换摄影**：保持同名文件放入 `web/static/assets/field/`；首屏图片建议控制在 200 KB 以内。
4. **上传格式**：支持「年份 + 日序（1—366）」或完整日期；完整日期可写在「日期」列，也可直接写在「日」列。缺失值留空，不要填 0。
5. **端口 5000 旧服务**：如果双击启动脚本前 5000 端口已有旧设计包服务，脚本会自动结束占用进程并启动本项目。
6. **sklearn 版本提示**：当前模型用 scikit-learn 1.5.2 训练，本机 1.9.1 加载时会打印 `InconsistentVersionWarning`，不影响启动与页面；预测结果已抽样验证在合理范围内，若需完全复现训练指标，建议用当前环境重新训练模型。

## 9. 一键启动器（2026-11-11）

启动链路改为「批处理 + Python 启动器」：

- `启动小麦系统.bat`：检测 Python（`python` / `py -3` / `D:\python`）、检查依赖、调用 `scripts/stop_app.ps1` 清理旧的 `app.py`/`run.py` 进程，然后前台运行 `run.py`。
- `run.py`：前台启动 Flask，后台预热数据与模型；通过 `http://127.0.0.1:5000/` 健康检查后，用系统默认浏览器打开页面。
- `scripts/stop_app.ps1`：只结束命令行包含 `app.py` / `run.py` 的 5000 端口进程，不误杀其他程序。
- 关闭控制台窗口即终止 Python 与 Flask，5000 端口释放；浏览器标签保留但刷新会无法连接。
- 支持 `python run.py --no-browser` 或环境变量 `WHEAT_NO_BROWSER=1`，用于自动化测试。
- 启动日志中已过滤 sklearn 版本提示和模型特征名提示，避免刷屏；不影响模型加载。
