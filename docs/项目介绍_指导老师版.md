# 河南省小麦气象数据分析与产量预测系统
## 项目介绍

---

## 一、项目背景
小麦是河南省最主要的粮食作物，产量直接关系到国家粮食安全。传统的产量预测主要依靠经验和统计方法，精度有限且时效性差。

本项目利用机器学习技术，结合气象数据和历史产量数据，构建小麦产量预测模型，实现精准预测和预警，为农业生产提供科学决策支持。

---

## 二、项目成果
| 指标 | 数值 |
|------|------|
| 覆盖区县 | 16个地级市、150+个区县 |
| 时间跨度 | 2010-2024年，共15年 |
| 产量标签 | 建模 1,635 条（110 县）；全量 2,228 条 |

## 三、核心功能

### 1. 数据管理
- **数据上传**：支持CSV/Excel格式的气象数据上传，自动校验格式
- **数据清洗**：自动去除异常值、补全缺失值、统一单位

### 2. 气象数据分析
- 多维度气象图表：温度、降水、风速、湿度等
- 生育期关键指标：积温、干热风天数、降水距平
- 综合评估：自动生成气象条件评价

### 3. 产量预测
- **多模型融合**：随机森林 + LightGBM + 线性回归，加权融合
- **区间预测**：MAE 近似区间，比点预测更实用
- **SHAP 因子贡献**：分解各因子对当年产量的推高/拉低方向与幅度

### 4. 预警系统
- **产量阈值预警**：自定义预警值，低于阈值自动报警
- **干热风预警**：专门针对小麦灌浆期的干热风灾害预警

### 5. GIS地图可视化
- 河南省县级地图，直观展示产量空间分布
- 支持切换年份、切换指标（单产/降水）
- 交互功能：悬停查看详情、缩放、拖拽

### 6. 情景模拟
- 滑块调整气象因子（温度、降水、干热风天数）
- 实时预测产量变化，直观展示气象因子的影响

### 7. 报告导出
- 支持Excel格式导出
- 支持PDF格式导出（含结论和建议）

## 四、技术架构
- **后端**：Python + Flask
- **前端**：HTML + CSS + ECharts
- **数据库**：MySQL（可选，内置CSV数据也能跑）
- **机器学习**：scikit-learn + LightGBM
- **地理信息**：ECharts + GeoJSON

---

## 五、创新点
1. **多模型融合策略**：结合三种模型优势，比单一模型更稳健
2. **区间预测**：给出 MAE 近似区间，更符合实际生产需求
3. **可解释性分析**：SHAP 贡献分解，让模型预测可追溯到具体气象因子
4. **多源数据融合**：整合NASA卫星气象数据、官方统计产量数据、GIS地理数据
5. **情景模拟功能**：交互式展示气象因子对产量的影响

---

## 六、项目意义
- **农业生产指导**：帮助农户提前了解产量趋势，合理安排生产
- **灾害预警**：及时预警干热风等农业灾害，减少损失
- **政府决策支持**：为粮食安全政策制定提供数据支撑
- **技术示范**：展示大数据和机器学习在农业领域的应用
