# 河南省小麦气象灾害影响分析与智能预警平台
## 交付检查清单（2026-11-18 版）

### 一、数据情况
- 覆盖：151 个气象县区；其中 **110 个县有真实产量标签参与建模**（城区只做气象分析）
- 时间：2010—2024 年，共 15 年
- 逐日气象：821,850 条；年度特征表 2,250 条；建模样本 1,635 条
- 全量标签 2,228 条 / 154 县（供灾害地图使用）
- 存储：MySQL 8.0（`wheat_ml`）4 张表；**MySQL 为可选加速层**，不可用时自动回退 CSV
- 来源：NASA POWER 逐日气象 + 省市统计年鉴产量

### 三、功能清单（25 个入口，提交前实测全部 200）
**页面 9 个**
1. `/` 系统概览
2. `/upload` 数据诊断（上传自愈 + 灾害识别）
3. `/datasets` 数据清单（已上传数据集 / 类型 / 删除 / 清空）
4. `/analysis` 气象分析（年度对比 + 当期观测对照）
5. `/map` 灾害地图
6. `/dry_hot` 干热风预警（只统计 110 个主产县的县级排行）
7. `/risk` 灾害预警（年度 110 县清单 + 顶部当期观测预警）
8. `/predict` 产量预测（情景仿真 + 误差量级 + D 区提示）
9. `/advice` 农事建议（五生育期作业卡 + 当期观测）

**导出 3 个**：`/export_risk`（Excel 14KB）、`/export_report`（Excel 5.9KB）、`/export_report_pdf`（PDF 62KB）

**接口 4 个**：`/api/map_data`、`/api/feature_importance`、`/api/simulate`（GET，带 county/year）、`/api/send-log`（POST，mark / unmark）

**操作 9 个**：`/upload/template` 模板下载、`/datasets/<id>/toggle`、`/datasets/<id>/delete`、`/datasets/clear`、`/reset_dataset`、`/advice/check`、`/advice/upload_stage`、`/advice/reset_stage`、`/advice/restore_stage`

### 五、已知局限（必须如实说明）
1. 偏离层解释力仅 10.1%，其余为土壤、品种、管理，数据不可得
