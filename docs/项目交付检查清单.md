# 河南省小麦气象灾害影响分析与智能预警平台
## 交付检查清单（2026-11-18 版）

### 一、数据情况
- 覆盖：151 个气象县区；其中 **110 个县有真实产量标签参与建模**（城区只做气象分析）
- 时间：2010—2024 年，共 15 年
- 逐日气象：821,850 条；年度特征表 2,250 条；建模样本 1,635 条
- 全量标签 2,228 条 / 154 县（供产量地图使用）
- 存储：MySQL 8.0（`wheat_ml`）4 张表；**MySQL 为可选加速层**，不可用时自动回退 CSV
- 来源：NASA POWER 逐日气象 + 省市统计年鉴产量

### 三、功能清单（19 个入口，实测全部 200）
**页面 8 个**
1. `/` 系统概览
2. `/analysis` 气象分析
3. `/map` 灾害地图
4. `/dry_hot` 干热风预警
5. `/risk` 灾害预警（110 县清单）
6. `/predict` 产量预测（情景仿真 + 误差量级 + D 区提示）
7. `/advice` 农事建议（五生育期作业卡 + 当期观测）
8. `/upload` 数据诊断（上传即识别灾害）

**导出 3 个**：`/export_risk`（Excel 13.6KB）、`/export_report`（Excel 96KB）、`/export_report_pdf`（PDF 230KB）

**接口 3 个**：`/api/map_data`、`/api/feature_importance`、`/api/simulate`（带 county/year 返回完整结果）

**操作 5 个**：`/advice/upload_stage` 分期上传、`/advice/reset_stage` 按段清空、`/advice/restore_stage` 撤销、`/advice/check` 作业勾选、`/reset_dataset` 恢复内置数据集
