# 河南省小麦气象数据分析与产量预测系统
## 项目交付检查清单

### 一、数据情况
- 覆盖区县：151 个气象县区；其中 110 个县有真实产量标签参与建模（城区仅作气象分析，不参与标签训练）
- 时间范围：2010-2024年，共15年
- 产量标签：1,635 条有真实标签的建模样本（110 县）；全量标签 2,228 条、154 县，供产量地图使用
- 数据库：MySQL 8.0（wheat_ml，127.0.0.1:3306）存县表、逐日气象 821,850 条、年度特征 2,250 条、产量标签 1,635 条；应用优先读 MySQL，异常时回退 CSV
- 气象数据：NASA POWER历史气象数据
- 数据来源：河南省统计局、各地市统计局、统计年鉴

### 二、模型情况
- 主模型：多模型融合（随机森林50% + LightGBM30% + 线性回归20%）
- 精度：最优随机森林 R²=0.9431，RMSE=21.07 kg/亩，MAE=16.21 kg/亩（LightGBM 0.9430、线性回归 0.8957）
- 特征数：19 个特征（18 个气象时序因子 + 1 个县域常年单产先验）
- 模型解释：SHAP 因子贡献分析（全局重要性 + 当年推高/拉低分解）、MAE 近似区间

### 三、功能模块
1. **数据上传与校验**：支持CSV/Excel上传，自动校验数据格式
2. **气象数据分析**：温度、降水、风速、湿度等多维度图表
3. **GIS地图可视化**：河南省县级地图，展示单产分布
4. **产量预测**：多模型融合预测，MAE 近似区间
5. **产量阈值预警**：自定义预警值，低于预警值触发预警
6. **干热风预警**：专门针对干热风灾害的预警
7. **农事建议**：根据气象条件生成农事建议
8. **情景模拟**：滑块调整气象因子，实时看产量变化
9. **报告导出**：支持Excel和PDF两种格式
10. **SHAP 因子贡献**：分解各因子对当年产量的推高/拉低方向与幅度

### 四、创新点
1. 多模型融合策略，结合三种模型优势，比单一模型更稳健
2. MAE 近似区间，比点预测更符合实际生产需求
3. SHAP 贡献分解，预测可解释、可追溯到具体因子
4. 分城市分组的区县下拉框，用户体验好
5. 情景模拟功能，直观展示气象因子对产量的影响

### 五、需要注意的问题
1. **数据匹配**：淮阳县/淮阳区的名称映射已经处理
2. **异常值**：已经去掉了明显异常的数据（单产<150或>700）
3. **市辖区/城区**：气象分析覆盖 151 个县区；模型标签只使用 110 个有真实产量的县
4. **模型精度**：最优单模型 R²=0.9431，对于比赛来说已经很高了

### 六、交付给第三个队员的建议
1. 主要优化前端界面，不要动核心代码和模型
2. 重点优化：页面美观度、交互体验、响应式布局
3. 保持现有功能不变，只改样式和布局
4. 答辩的时候要突出：数据覆盖广、模型精度高、功能完整、创新点多
