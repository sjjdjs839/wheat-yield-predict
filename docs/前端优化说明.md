# 前端优化说明

## 给前端队员的要求
主要优化界面美观度和交互体验，**不要动核心代码和模型逻辑**。

---

## 可以改的部分（前端优化）
1. **CSS样式**：`web/static/style.css`
   - 颜色、字体、间距、圆角、阴影
   - 页面布局、按钮样式、卡片样式
   - 响应式适配（手机端也能看）

2. **HTML模板**：`web/templates/`
   - 页面布局、排版
   - 加图标、加动画效果
   - 优化表格、表单的样式

3. **地图样式**：`web/templates/map.html`
   - 地图颜色配色
   - 图例样式
   - 交互效果（悬停、点击）

---

## 不要动的部分（核心逻辑）
1. **app.py里的后端路由**：不要改API逻辑
2. **模型加载和预测逻辑**：不要动
3. **数据加载逻辑**：不要动
4. **变量名和接口参数**：不要改，改了会报错

---

## 项目结构
```
wheat-ml/
├── app.py              # 后端主程序（不要改逻辑）
├── web/
│   ├── templates/      # HTML模板（可以改样式布局）
│   │   ├── base.html   # 基础模板（导航栏在这里）
│   │   ├── index.html   # 系统概览
│   │   ├── upload.html  # 数据上传
│   │   ├── analysis.html # 气象分析
│   │   ├── map.html    # 产量地图
│   │   ├── dry_hot.html # 干热风预警
│   │   ├── predict.html # 产量预测
│   │   └── advice.html  # 农事建议
│   └── static/
│       ├── style.css    # 样式文件（主要改这里）
│       └── henan_county.json # 河南地图数据
├── config/
│   └── config.yaml     # 配置文件（不要动）
└── output/
    └── models/          # 训练好的模型（不要动）
```

---

## 运行方式
```bash
cd wheat-ml
python app.py
```
然后浏览器打开：http://127.0.0.1:5000

---

## 注意事项
- 改完样式直接刷新页面就能看到效果
- 不要改HTML里的id、class名字，不然JS会失效
- 不要改后端API的返回格式
- 重点优化：首页美观度、表格样式、按钮样式、地图配色
